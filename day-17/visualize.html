① 打字机回答 左:非流式整段蹦出 右:流式逐 token 流出

非流式（等 TTFT 后整段） 流式（首字立刻 + 逐 token）

流式不缩短总时长，只把"首字延迟 TTFT"砍到极低——体验立刻翻倍。

② SSE 事件流 message_start → content_block_delta*N → message_stop

每个 token = 一行 data: 事件。客户端剥掉 data: 前缀 → 解析 JSON → 拼接 delta = 完整回答。这就是 EventSource 在做的事。
