Day 37 · LangChain 四件套

Chain=函数串联 · Memory=历史list · Tool=注册表 · Agent=ReAct循环 — 全是后端老套路，点开看每块怎么动

① Chain prompt模板 → 模型 → 解析（LCEL 的 |）

数据逐段流过：变量填进模板 → 调模型 → 解析输出。竖线就是函数 compose。

② Memory 对话历史 list，模型本无记忆

每轮 append 用户+AI，越堆越高一起发回去——这就是"记忆"，跟 session 一样。

③ Tool 名字 → 函数 注册表 = dispatch table

模型说调谁，代码查表执行。点工具看命中哪格。

④ Agent ReAct 循环：Reason→Act→Observe

while 里转圈：想→选工具→看结果→再想，直到 ANSWER。Tool+Memory+Chain 的编排。
