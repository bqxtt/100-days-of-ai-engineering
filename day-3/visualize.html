每个词拿 query 去匹配全场 key → 缩放点积 → softmax → 按权重取 value，权重热力图全程可玩

① 输入 tokens 改这句话，下面的注意力立刻重算

类比:数据库查询 随机重投影

每个 token 投影成 Q/K/V 三种身份；query 去问全场 key，谁像谁就给谁高权重。

② 注意力权重热力图 第i行=token i 分给全场的注意力，行和=1

颜色越亮=越关注。把鼠标移上去看该词具体看了谁多少。每行越亮越分散=缩放够大。

③ 缩放 √d_k 的威力 温度=softmax 锐度，对应 ÷√d_k

选中行 0

温度→小：softmax 塌成 one-hot（只盯一个词）；温度→大：权重趋于平均。这就是 √d_k 在调的事。
