## 📖 学习内容（约 25 分钟）

### 1. 神经网络 = 一个带可学习参数的函数

后端工程师每天都在写函数：`output = f(input)`。神经网络也是一个函数，区别只有一点：
它的"配置"（权重）不是你手写的常量，而是**从数据里自动学出来的**。

```
传统后端逻辑：   if user.age > 18 and user.score > 60: pass   # 规则是人写死的
神经网络：       output = f(input; W)                         # 规则藏在 W 里，自动学
```

一个最小的"神经元"做两件事：
1. **加权求和**：`z = w1*x1 + w2*x2 + ... + b`（就是一次点积 + 偏置）
2. **激活**：`a = σ(z)`（套一个非线性函数）

把很多神经元按层堆起来，就是**前馈网络（Feed-Forward Network, FFN）**。数据从输入层一路往前流到输出层，不回头——所以叫"前馈"。这正是 Transformer 里每个 block 的核心组件之一，所以今天不是白学。

### 2. 为什么必须有激活函数（关键直觉）

如果去掉激活函数，无论你堆多少层，`W3·(W2·(W1·x))` 仍然等价于一个矩阵 `W·x`——**多层会塌缩成一层**，等于没堆。激活函数引入非线性，才让网络能拟合复杂关系。

| 激活函数 | 公式 | 直觉 | 用在哪 |
|---|---|---|---|
| Sigmoid | `1/(1+e^-x)` | 压到 (0,1)，像概率 | 老网络/二分类输出 |
| ReLU | `max(0, x)` | 负的归零，正的不变 | 隐藏层默认选择 |
| GELU | `x·Φ(x)` | ReLU 的平滑版 | **Transformer 用这个** |
| Softmax | `e^xi / Σe^xj` | 一组数→概率分布 | 多分类/注意力权重 |

记住一条：**隐藏层用 ReLU/GELU 引入非线性，输出层用 Softmax 把数变成概率**。后面学 Attention 时，softmax 又会出现。

### 3. 反向传播 = 自动追责的链式求导

训练就三步循环：
1. **前向**：算出预测值
2. **算 Loss**：预测和真实差多少（如 `MSE = (pred-true)²`）
3. **反向**：算出"每个权重该为这个错误负多少责"，然后微调

"追责"用的是**链式法则**——和你排查一条调用链上哪个服务拖慢了请求一模一样。梯度就是"这个参数动一点，loss 会变多少"。沿梯度反方向走一小步（学习率 lr），loss 就下降一点。重复几万次就"学会了"。

```
W = W - lr * dLoss/dW     # 这一行就是深度学习的全部秘密
```
