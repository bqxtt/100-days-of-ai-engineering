# Day 41 笔记 · Memory 系统设计：短期 / 长期 / 摘要

## 三种记忆一句话
- 短期记忆（short-term）= 对话历史窗口，类比**缓存**：最近 N 轮，命中快、满了挤旧。
- 长期记忆（long-term）= 向量库存事实，类比**数据库**：nomic 嵌入 + 余弦检索，按相关性召回。
- 摘要记忆（summary）= 超窗口让模型 summarize 旧消息，类比**日志归档**：冷数据压成一句，省 token。
