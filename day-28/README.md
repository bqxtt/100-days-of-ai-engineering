# Day 28 — 基础 RAG Pipeline（下）：检索 → 拼 prompt → 生成 → 引用

> **阶段**：Phase 3 · RAG 系统设计与实现
> **主题**：把知识库用起来——top-k 检索（retrieve）、拼 context 装 prompt、带引用生成、防幻觉兜底
> **预计耗时**：约 1 小时
> **给后端工程师的一句话**：Day 27（上）做的是"建库"——加载、分块、嵌入、入库；今天（下）做的是"用库"。RAG 的下半场骨架短得离谱：**问题嵌成向量 → 和库算相似度取 top-k → 把这几条塞进 prompt → 让模型只照资料作答并标 [编号]**。模型不靠脑子里的旧知识，全凭你递给它的 context，所以"答得准不准"主要取决于"检索捞得对不对"。这正好是后端拿手戏：检索是查库、拼 prompt 是拼接模板、生成是调下游服务、防幻觉是兜底降级。

## 📖 学习内容（约 30 分钟）

### 0. 承上启下：Day 27 建库，Day 28 用库

```
Day 27（上）：原始文档 → 分块(chunk) → 嵌入(embed) → 存进向量库      [离线，建一次]
Day 28（下）：问题 → 嵌入 → 检索top-k → 拼context → 生成带引用 → 防幻觉   [在线，每次问]
```

今天只管下半场，4 个模块就是一条流水线。后端类比：上半场=灌数据建索引，下半场=收到请求查索引再渲染响应。

### 1. retrieve top-k：把问题和库放一起量"像不像"

问题先用嵌入模型（**nomic-embed-text**）变成向量，再和库里每条文档的向量逐一算**余弦相似度（cosine similarity）**，分高的就是最相关。取前 k 条（top-k）即可。

```
qv = embed(question)
scored = [(cosine(qv, doc_vec), doc) for doc_vec, doc in 库]
top_k = 排序后取前 k 条
```

工程要点：nomic 要加任务前缀——文档用 `search_document:`、问题用 `search_query:`，检索更准（这是它的官方用法）。k 不是越大越好：太小怕漏，太大把无关片段塞进 context 反而稀释、抬成本。今天 k=2 起步。

### 2. context 拼装 prompt：给模型"开卷"，并锁死作答范围

把 top-k 编号拼成 context，用一段 system 风格的指令把模型框死：**只看资料、按编号引用、没有就认怂**。

```
只根据下面资料回答，引用编号如 [1]；资料里没有就答「资料中未提及」。
资料：
[1] 食堂午餐时间为 11:30 至 13:00…
[2] VPN 账号由 IT 部统一分配…
问题：食堂几点开饭？
```

后端类比：context 就是你查库后渲染进模板的数据，prompt 就是模板。模型本身无状态，**给什么资料决定它能答什么**——把对的片段递进去，是整条链路质量的命门。

### 3. 生成带引用：可溯源比"答得漂亮"重要

让生成模型（**qwen2.5:3b**）照资料作答，并标 [编号]。引用让答案**可追溯**——用户能点开看出处，你能审计模型有没有照资料、还是自己编。temperature=0 让它别发挥，老实复述。这是 RAG 区别于"裸聊"的关键：每句话都能指回某条文档。

### 4. 防幻觉：两道闸，宁可不答也别瞎编

- **第一道（检索侧）**：最相关一条的相似度都低于阈值 → 直接答"资料中未提及"，根本不进生成。问题离库太远就不硬答。
- **第二道（prompt 侧）**：指令明写"资料里没有就答未提及"，即便检索误捞了高分无关片段，模型也不会硬凑。

试问"公司养了几只猫"：库里没有，第二道闸兜住，模型答"资料中未提及"。**幻觉的本质是"逼模型回答它不知道的事"，RAG 防幻觉的关键就是给它退路。**

### 从 Ollama 到真实 Claude：只换"生成"一步

`practice.py` 嵌入走 nomic、生成走 qwen2.5:3b，全本地免费。接真实模型时，把 `generate()` 换成 Anthropic SDK 一行调用，检索 / 拼 context / 引用约束 / 防幻觉**一行不改**——核心逻辑与生成后端解耦。

## 🤔 思考题（边做边想）

1. 检索捞错了片段，模型大概率也答错——这意味着 RAG 质量的瓶颈在生成还是检索？该先优化哪头？
2. context 越长越好吗？把 top-k 调到 10 会怎样（成本、相关度稀释、上下文窗口）？这和后端"一次查太多数据拖慢接口"像不像？
3. 防幻觉的相似度阈值设太高/太低分别会怎样？这和你调线上告警阈值的权衡是不是一回事？
4. 引用 [编号] 能让答案可溯源——若用户点开发现引用对不上原文，链路哪一步可能出问题？
5. 接真实 Claude 只换 generate 一步，检索/拼prompt不变——这种"模型可替换"的设计，对你做模型选型/降本意味着什么？
