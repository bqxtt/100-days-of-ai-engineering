Day 16 · 图片如何变成一串 token

一张图 → patch 网格切分 → 拍扁成向量 → 拉成序列接到文字后面，全都能动手玩

① 原图 换图案 + 调 patch 大小

渐变 圆 十字 噪点

patch 越小 → 视觉 token 越多 → 理解越细但越贵越慢。

② patch 网格切分 每块 = 一个视觉 token

128×128 图按 16px patch = 8×8 = 64 个 patch。和 Day 6 切词同理，只是源换成了切图。

③ 序列化：图 token 接到文字 token 后面 这就是多模态 message

视觉 token — 估算总 token — ≈ tokens (宽×高)/750 + patch 数

"describe" 2 个文字 token + 一堆图 token 拼成一条序列，进同一个 Transformer；token 越多越贵。
